# IAD

## Лабораторная работа 1

Лабораторная работа №1 - создание генетического алгоритма.
- Задача: о назначениях
- Отбор: турнирный
- Условия окончания: больше 1000 итераций или нет изменений в последних 3 поколениях.

### Теория, которую нужно знать

**Генетический алгоритм**
- Определение
- Блок-схема
- основные определения (хромосома, ген, популяция, приспособленность)

**Модели выбора родителей**
- Инбридинг
- Аутбридинг
- Панмиксия

**Операторы скрещивания**
- Кроссовер (одноточечный, двухточечный)
- Дискретная рекомбинация
    - Дискретная рекомбинация
    - Промежуточная рекомбинация
    - Линейная рекомбинация

**Операторы мутации**
- Мутация
- Инверсия

**Операторы отбора**
- Рулетка
- Рулетка с остатками
- Турнирный
- Отбор усечением
- Ранговый

### Файлы

- GA_abstract.py - абстрактный класс для особи и для популяции
- lab1.py - особь и популяция
- lab1_test.py - код тестирования. Начинать смотреть отсюда.

### Заметки для презентации по миграционному ГА
- Находимость решений улучшилась с введением миграций.
- В случае установки плато = 3, в "идеальном" случае алгоритм находит правильное решение примерно в 70% случаев. В остальных - примерно в 63%; при увеличении плато количество итераций возрастает в десятки раз.
- Из-за агрессивного отбора алгоритм быстро приходит к локальному экстремуму и останавливается по условию плато, не доходя до обмена особями. (плато: 3, обмен раз в 10 итераций)
    - При этом обмен не оказывает заметного влияния на результаты алгоритма.
    - Если же поставить условие плато заметно больше 3, например, 10, то ГА на случайных данных показывает те же результаты, но на "идеальных" данных перестаёт работать.
